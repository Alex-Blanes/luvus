Luvus v0.12.0 adds native code review, global fuzzy search, community themes, safe updates, and the Luvus Bar extension surface. Existing Luvus workflows and configuration remain available after upgrading from v0.11.0.

## Features

- **DIFF review:** Inspect staged, worktree, untracked, and conflicted changes, leave local line notes, and send focused feedback to a live agent ([`f0840ba`](https://github.com/RizRiyz/luvus/commit/f0840ba), [`011890c`](https://github.com/RizRiyz/luvus/commit/011890c7c8d929a00aef9b41fbbec051ddc45c50), [#83](https://github.com/RizRiyz/luvus/pull/83)).
- **Git Status:** Open the explicitly selected staged or working-tree change directly in the native DIFF viewer ([`6bd06d9`](https://github.com/RizRiyz/luvus/commit/6bd06d9), [`93d7810`](https://github.com/RizRiyz/luvus/commit/93d7810d45bdd65606f02c0a450c60a05403e2fe), [#70](https://github.com/RizRiyz/luvus/pull/70)).
- **Global search:** Find sessions, workspaces, tabs, panes, agents, files, and retained terminal output from one fuzzy finder ([`60d486e`](https://github.com/RizRiyz/luvus/commit/60d486e), [`06de1c3`](https://github.com/RizRiyz/luvus/commit/06de1c3cbc415935ed55a0e57c01542dd831090e), [#84](https://github.com/RizRiyz/luvus/pull/84)).
- **Themes:** Create, compose, validate, and install safe community themes from local files, HTTPS URLs, or public GitHub repositories ([`866c6d5`](https://github.com/RizRiyz/luvus/commit/866c6d535e6668a37d30a2e40e68d42ab19ae18a), [`b8ca50f`](https://github.com/RizRiyz/luvus/commit/b8ca50f), [`936c314`](https://github.com/RizRiyz/luvus/commit/936c314), [#81](https://github.com/RizRiyz/luvus/pull/81), [`ba5b884`](https://github.com/RizRiyz/luvus/commit/ba5b884), [`d3d19a4`](https://github.com/RizRiyz/luvus/commit/d3d19a46f2c58071023609db81a595cd8d4b7754), [#82](https://github.com/RizRiyz/luvus/pull/82)).
- **Luvus Bar:** Let modules publish compact status, progress, badges, and actions beside tabs or in the bottom status row ([`5a2b59d`](https://github.com/RizRiyz/luvus/commit/5a2b59d), [`7707e12`](https://github.com/RizRiyz/luvus/commit/7707e12), [`971e113`](https://github.com/RizRiyz/luvus/commit/971e1133d5d7557762eb0311c3d0741dab0138a3), [#80](https://github.com/RizRiyz/luvus/pull/80)).
- **Workspaces:** Browse filesystem paths directly while choosing or creating a workspace ([`0c8ec16`](https://github.com/RizRiyz/luvus/commit/0c8ec160fc227e900c2784746448463fc93411fd), [#79](https://github.com/RizRiyz/luvus/pull/79)).
- **Tabs:** Reorder tabs precisely or swap any two tabs from the menu, TUI, CLI, or socket API ([`010898a`](https://github.com/RizRiyz/luvus/commit/010898a834d8481d24c45f16a46638256fa45615), [#75](https://github.com/RizRiyz/luvus/pull/75)).
- **Agents:** Detect fx sessions and report their activity state natively ([`639cb6b`](https://github.com/RizRiyz/luvus/commit/639cb6bb04d21242e7e59774d331a0cfabcc18e9), [#77](https://github.com/RizRiyz/luvus/pull/77)).
- **Updates:** Run `luvus update` to safely upgrade direct, Cargo, or Homebrew installs after checking the release version and checksum, then copy the command from the Changelog ([`22096f0`](https://github.com/RizRiyz/luvus/commit/22096f0), [`4feb02c`](https://github.com/RizRiyz/luvus/commit/4feb02c06de9ff058a1956d5cf745108f0e60f32), [#88](https://github.com/RizRiyz/luvus/pull/88), [`5bb7851`](https://github.com/RizRiyz/luvus/commit/5bb7851), [`5e8d19b`](https://github.com/RizRiyz/luvus/commit/5e8d19bc7b4bfb2955e27e2106fbdec9c41d2cf1), [#90](https://github.com/RizRiyz/luvus/pull/90)).

## Improvements

- **Files:** Refresh Git diffs and file trees off the app loop to keep interaction responsive in larger repositories ([`6ff5d92`](https://github.com/RizRiyz/luvus/commit/6ff5d92fd357e00debcaae495c8fc952f4907f1c), [#85](https://github.com/RizRiyz/luvus/pull/85)).
- **Copy mode:** Preserve terminal selections more reliably and provide a focused keyboard copy workflow ([`ad17758`](https://github.com/RizRiyz/luvus/commit/ad1775819e4a2c78dce2ce987a1c1c5acd63aa84), [#74](https://github.com/RizRiyz/luvus/pull/74)).

- **Website:** Refresh shared Open Graph artwork, showcase native DIFF review and the Luvus Bar, and add X links across the public site ([`2b2a8d8`](https://github.com/RizRiyz/luvus/commit/2b2a8d8), [`5bb7851`](https://github.com/RizRiyz/luvus/commit/5bb7851), [`5e8d19b`](https://github.com/RizRiyz/luvus/commit/5e8d19bc7b4bfb2955e27e2106fbdec9c41d2cf1), [#90](https://github.com/RizRiyz/luvus/pull/90)).
