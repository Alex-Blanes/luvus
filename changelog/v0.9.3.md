New looks and new reach: Catppuccin and Gruvbox themes, native .deb/.rpm packages and a NixOS install, a mobile-friendly compact layout, and a Buzz chat example module. Plus a configurable Shift+Enter and fixes for emoji rendering, agent sessions, pasting into Settings, and the file tree. Fully compatible with v0.9.2, nothing to migrate.

### ✨ Added

- **Catppuccin and Gruvbox themes.** All four Catppuccin flavours (Mocha, Macchiato, Frappe, Latte) and Gruvbox dark and light, in Settings → Theme and on the website. ([`59a2bd5`](https://github.com/RizRiyz/bohay/commit/59a2bd5c72bd5ce1676cd41180288528f3172e39))
- **Native Linux packages.** Every release now ships a `.deb` and a `.rpm` for x86_64 and arm64, so `apt install ./bohay.deb` / `dnf install ./bohay.rpm` just work. ([`408505f`](https://github.com/RizRiyz/bohay/commit/408505fd88c15e6e90f553a4688fe8c49623a97a))
- **NixOS install.** A flake so you can `nix run github:RizRiyz/bohay` or add it to a config, with the runtime tools baked in. ([`2fa48c2`](https://github.com/RizRiyz/bohay/commit/2fa48c21d9c4587dada55bc2d8f4063a5e7c96b5))
- **Mobile-friendly panes.** Tap a pane to zoom it, and a leaner compact layout for narrow screens like a phone over SSH. ([`9d16cac`](https://github.com/RizRiyz/bohay/commit/9d16cacc092244daaa4e17cea4e1929589d4c4bc))
- **Configurable Shift+Enter.** Pick what Shift/Alt+Enter sends to a pane ("new line, don't submit") in Settings, since agents and terminals disagree on the byte sequence. Defaults to what Claude Code's terminal setup installs, with a plain newline and CSI-u options for the ones that want them. ([`38c6efa`](https://github.com/RizRiyz/bohay/commit/38c6efa7b92b7e8e77a754d676570dcfbdec391e))
- **Buzz chat example module.** An IRC-like nostr chat client (NIP-29) you run as a bohay module, talking directly to a Buzz relay. Clickable channels, colored nicks, and a right-click action to share a pane into chat. Lives in `examples/modules/buzz`. ([`1a9f6f9`](https://github.com/RizRiyz/bohay/commit/1a9f6f940c8ba2f98cbf98a5179b7b8cb6d8a8df))

### 🐛 Fixed

- **Emoji render correctly in panes.** A double-width glyph no longer smears into the next cell and shifts the rest of the row (or the sidebar), and emoji with variation selectors or ZWJ sequences render whole instead of as a box. Done on the render hot path with zero extra allocation on the common cell. ([`6814ac6`](https://github.com/RizRiyz/bohay/commit/6814ac65c5bd4c7dd78b1ee1564efbcf589f56f5), [`0a6ec7d`](https://github.com/RizRiyz/bohay/commit/0a6ec7d2eea720ed6b5d47cb9dd1fffd4d20ec10))
- **Agent sessions stay put.** Each pane keeps its own agent session and shows in the agent list, and a restore never restores one session into two panes. ([`ff13b05`](https://github.com/RizRiyz/bohay/commit/ff13b059db832c213cb834976eee07d4eef46fa5), [`863fb8b`](https://github.com/RizRiyz/bohay/commit/863fb8b7cafadf251c90a459951b5b1920e42542))
- **Paste fills Settings fields.** Pasting into a Settings field (or any text prompt) now fills the field instead of leaking to the pane underneath. ([`acae381`](https://github.com/RizRiyz/bohay/commit/acae3812e99fc568db14ad36f3fc55304656ad36))
- **`bohay` in a pane targets its own session.** The CLI now honors the injected socket, so a command run inside a pane reaches that session's server rather than a default one. ([`c600048`](https://github.com/RizRiyz/bohay/commit/c600048b19ffe88a6ed6e32d1802d9a1c6d6073e))
- **File tree hidden-files toggle restored.** ([`ded32f9`](https://github.com/RizRiyz/bohay/commit/ded32f9d27f39cd51b5b41207b346fc8698593e4))
- **Correct keyboard report on Windows.** `bohay doctor` now reports Windows keyboard support accurately, where it reads keys from native console records rather than the keyboard protocol. ([`38c6efa`](https://github.com/RizRiyz/bohay/commit/38c6efa7b92b7e8e77a754d676570dcfbdec391e))
- **Cleaner splits and redraw.** A drag started inside a pane no longer grabs the divider, and a client that falls behind resyncs promptly. ([`58ebd87`](https://github.com/RizRiyz/bohay/commit/58ebd87c8b2727260a72664cd456e68719c3fc3d))
